客户与客服双端入口现为 `/service`，登录后按身份展示专属页面。支持智能咨询、转人工、分级客服接单、更换客服和客户确认完成；演示账号与验收步骤见 [客户与客服双端使用说明](docs/02-项目说明/客户与客服双端使用说明.md)。

当前项目位于 `E:\oshino`，在 `XM` 分支跟写毕业设计。已实现异步 PostgreSQL、登录、客服账号、基础配置、工单管理闭环，以及第四部分 CSV 历史工单导入。第五部分已接入本地 Qwen3-Embedding-0.6B，保留 33 条有效案例索引；第六部分已实现真实知识库，原有 4 份模拟文档之外，本机另发布了 200 条独立产品下的 CSDS 客服问答演示资料并重建知识索引。第七至十二部分已接入 AI 建议与人工采用、评测脚本、真实统计看板、工单基础分析、测试邮箱发送流程和 OCR/PDF 知识草稿导入。第十三部分已加入智能助手入口、产品知识问答、会话保存和来源展示。

工单列表、新建、编辑和详情连接真实后端，数据写入 PostgreSQL。知识库支持文档上传、草稿、发布、停用和工单知识检索。智能助手从已发布知识中检索，按登录用户保存会话。统计看板读取 PostgreSQL。聊天模型的真实输出质量、SMTP 实际投递和 OCR 识别质量仍需分别人工验收；缺少模型或邮件配置会显示明确错误，不会伪造成功结果。

聊天配置步骤见 [第七部分](docs/01-教程/06-08-知识库与AI建议/07-AI处理建议.md)。

管理中心使用一层导航：数据统计、人员管理、基础资料、历史导入、回答评测。基础资料采用左侧列表与右侧表单，支持类型筛选、名称搜索和分页；模块所属产品创建后只读。人员管理合并客户名单与客服账号操作，只有管理员可新增、启停客服；基础资料和历史导入也仅管理员可见。历史导入复用 CSV 流程，原 `/tickets/import` 和 `/admin?tab=imports` 均转到 `/admin/imports`。连接检查入口已从导航移除，健康接口和 `/health` 直接地址保留。

客服智能助手新增步骤耗时、Token 和上下文记录；详情及评测口径见 [智能助手运行记录与回答评测](docs/02-项目说明/2026-11-02-智能助手运行记录与评测.md)。真实模型联调仍发现 JSON 结构校验失败，尚未完成固定题集的真实回答验收；自动测试通过不代表回答质量通过。

管理员可在“管理中心 → AI 服务”配置聊天模型与 DeepSeek 独立联网搜索。客服在智能助手按轮选择是否联网，回答展示网页引用，运行详情记录搜索步骤。配置保存在后端私有目录，留空保留密钥；固定题集和客户咨询仍只使用知识库。配置、迁移与验收见 [AI 服务与联网搜索](docs/02-项目说明/2026-11-04-AI服务与联网搜索.md)。

## 后端启动

使用已配置的 Docker 开发环境时，在 WSL 项目根目录运行：

```bash
cd /mnt/e/oshino
docker compose --env-file .env.docker up -d --build --wait
```

网页仍为 `http://127.0.0.1:18734/`。首次初始化、账号位置、源码更新与数据库说明见 [Docker 开发环境](docs/02-项目说明/Docker开发环境.md)。下面的命令用于直接在 WSL 运行，不要与容器服务同时占用相同端口。

当前后端使用 Python 3.12、FastAPI、SQLAlchemy 异步会话和 PostgreSQL。本机继续复用已安装的 Python 虚拟环境；激活环境与进入工程目录是两个步骤：

```bash
source /mnt/e/oshino/.venv/bin/activate
cd /mnt/e/oshino/backend
python -m uvicorn app.main:app --reload --port 8000
```

激活路径指向本机现有虚拟环境，后端工作目录是本仓库的 backend。后端依赖清单在 `backend/requirements.txt`，开发检查依赖在 `backend/requirements-dev.txt`。首次配置、迁移与管理员初始化见第二部分使用说明；已有配置和账号无需重新初始化。

健康接口：`http://127.0.0.1:8000/api/health`；接口文档：`http://127.0.0.1:8000/docs`。

## 前端启动

在另一个 WSL 终端运行：

```bash
source "$HOME/.nvm/nvm.sh"
nvm use 24
cd /mnt/e/oshino/frontend
npm run dev -- --port 18734
```

页面地址是 `http://127.0.0.1:18734/`，登录页为 `/login`，连接检查页为 `/health`。`/api` 请求代理到本机 8000 端口。Vite 配置默认端口仍是 `5173`；这里沿用第二部分的本机启动端口，避免与其他服务冲突。

首次安装或依赖变化后，在 `frontend` 运行 `npm ci`。代码修改后按需运行 `npm run typecheck`、`npm run build`；日常启动无需重复安装依赖。

已有后续章节的空文件继续保留。未实现迁移使用 `.py.pending` 后缀，完成对应章节后改回 `.py` 并加入 Dockerfile；未实现的 Vue 文件列在 frontend/tsconfig.json 的 exclude 中，写好时同步移除对应排除项。当前业务文件均参与类型检查。

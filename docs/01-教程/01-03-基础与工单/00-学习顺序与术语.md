# 学习顺序与术语

## 先记住这张“分工表”

| 名称 | 大白话解释 | 本项目放哪里 |
|---|---|---|
| 前端 | 你看得到、点得到的页面 | frontend |
| 后端 | 接收请求、判断能不能做、执行操作的程序 | backend |
| 接口 | 前端和后端约好的“办事窗口” | /api/health、/api/tickets 等 |
| 数据库 | 用来长期保存账号和工单的仓库 | PostgreSQL |
| 请求 | 页面发给后端的操作和数据 | fetch |
| 响应 | 后端返回的结果或错误 | JSON |
| 路由 | 决定“这个网址由谁处理” | 后端 APIRouter、前端 Vue Router |
| 类型 | 说明数据应该长什么样 | Python 类型、TypeScript 类型 |
| 校验 | 真正检查输入是否符合要求 | Pydantic、Zod |
| 迁移 | 按版本修改数据库表的脚本 | Alembic migrations |
| 事务 | 一组修改一起成功，失败则不留下半套结果 | SQLAlchemy Session |
| 令牌 | 登录后发给浏览器的临时通行凭证 | JWT |
| 哈希 | 用于核对密码的单向计算结果 | password_hash；不保存明文密码 |

先把代码写出来并跑通，再读解释。不要一次把所有库都研究完。

## 你每次打开电脑的操作顺序

1. 打开 WSL Ubuntu 终端。
2. 激活 Python 环境：`source /mnt/e/xiangmu/.venv/bin/activate`。
3. 第二部分开始，需要确保 PostgreSQL 在运行。
4. 在 backend 目录启动后端，保持这个终端运行。
5. 新开另一个 WSL 终端，在 frontend 目录运行 `npm run dev`。
6. 用浏览器打开前端网址。终端里按 Ctrl+C 可以停止对应服务。

终端提示符里的 `(.venv)` 表示 Python 环境已激活；
它不会自动把当前目录切到 backend。

## 按什么顺序写文件

### 第一部分

后端 `main.py` → 前端 `package.json`、`tsconfig.json`、`vite.config.ts`、`index.html`
→ `src/api/health.ts` → `src/App.vue` → `src/main.ts`。

### 第二部分

后端依赖与本地配置 → `core/settings.py` → `core/database.py` → `models.py`
→ 用户 schemas → `core/security.py` → 用户 router → 配置 schemas 和 router
→ `main.py` → Alembic 文件 → `configure.py`、`seed.py`。

前端依赖 → `api/models.ts` → `api/http.ts` → users/config API
→ auth store → LoginView、AdminView、HealthView → router → App、main、样式。

这些文件互相引用。一个文件写完、另一个还没有创建时，编辑器可能暂时报“找不到模块”；
先按顺序把本阶段需要的文件补全，再执行检查。

### 第三部分

增加工单模型与新迁移 → tickets schemas → service → router
→ 在 `main.py` 注册 router → 前端工单 schema 和 API
→ 工单列表、编辑、详情页面 → 更新前端 router 与导航。

## 四种常见符号

- Python 中 `def` 定义函数，缩进表示哪些代码属于这个函数。
- TypeScript 中 `const` 定义一个变量名绑定，`function` 定义函数。
- `import ... from ...` 或 Python 的 `from ... import ...` 都是在使用其他文件提供的功能。
- `await` 表示等待异步操作完成，比如等后端把结果返回。

## 怎么看“固定”和“可改”

1. **语法固定**：关键字和框架 API 需要按规定拼写，例如 `await`、`app.get`、`v-model`。
2. **命名可改**：自己起的变量名、函数名可以改，但使用它的地方要一起改。
3. **约定联动**：接口路径、JSON 字段、表名可以设计，但前后端和迁移要同步。
4. **显示可改**：页面标题、按钮文字、颜色可以先放心尝试。
5. **本地必填**：数据库密码、签名密钥由你自己的环境提供，不能拿教程占位文字当真实配置。

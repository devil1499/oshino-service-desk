# 逐文件代码与大白话讲解

这份文档按第一、第二、第三部分排列。源码直接保存在本页代码块中，按阶段顺序阅读。
你可以用 Ctrl+F 搜索文件名，例如 TicketEditor.vue。

每个文件会说明：它干什么、哪些是库要求的写法、哪些是项目自己决定的内容。
同一文件与上一部分完全相同时，只标明沿用，避免让你误以为还要重写。

## 阅读时记住

- 源码路径中的 backend 或 frontend，对应你正式工程里同名目录。
- “固定 API”指库识别的方法、参数或语法，不是说所有变量名都不能改。
- “可改”也要看联动：改颜色通常只动 CSS；改字段名往往涉及前后端和迁移。
- package-lock.json 由 npm 生成和维护，不需要手工逐行输入。
- 迁移文件的 revision/down_revision 是一条版本链，不能随意改成互不关联的字符串。
- 空的 __init__.py 可以保持为空。
- 测试文件用于自动验证行为，先理解业务代码，再回来看它们怎样调用接口。

## frontend/src/api/health.ts

对应源码：`frontend/src/api/health.ts`（源码见本教程对应代码块）

**作用：** 发送健康检查请求，并在收到响应处检查 status。

**固定 API / 约定：** fetch、AbortSignal.timeout、response.ok/json 是浏览器 API。

**可改内容：** 接口路径和成功结果要前后端一起改；5 秒是本示例选定的超时。

**阅读顺序与原因：** 先检查 HTTP，再把 JSON 当 unknown 检查，最后返回已经确认的 status。没有请求成功的默认兜底。


```typescript
export interface HealthResponse {
  status: 'ok'
}

export async function getHealth(): Promise<HealthResponse> {
  const response = await fetch('/api/health', {
    signal: AbortSignal.timeout(5000),
  })

  if (!response.ok) {
    throw new Error(`健康检查请求失败：HTTP ${response.status}`)
  }

  const data: unknown = await response.json()

  if (
    typeof data !== 'object' ||
    data === null ||
    !('status' in data) ||
    data.status !== 'ok'
  ) {
    throw new Error('健康检查响应不符合约定，应返回 {"status":"ok"}')
  }

  return { status: data.status }
}
```

## backend/app/configure.py

对应源码：`backend/app/configure.py`（源码见本教程对应代码块）

**作用：** 根据输入的本机数据库密码，生成 .env 或 .env.test。

**固定 API / 约定：** getpass、argparse、quote、Path 是 Python 标准库工具。

**可改内容：** after_sales、127.0.0.1、5432 是本教程选定的本机环境；可按实际环境同步调整。

**阅读顺序与原因：** getpass 隐藏输入，quote 处理密码里的 URL 特殊字符，open('x') 拒绝覆盖已有文件。只报告写入完成，不声称已连接数据库。


```python
import argparse
from getpass import getpass
from pathlib import Path
from secrets import token_urlsafe
from urllib.parse import quote


def main() -> None:
    parser = argparse.ArgumentParser(description="为本机 PostgreSQL 生成后端配置")
    parser.add_argument("--test", action="store_true", help="生成专用测试数据库配置")
    args = parser.parse_args()
    filename = ".env.test" if args.test else ".env"
    target = Path(__file__).resolve().parents[1] / filename
    if target.exists():
        raise SystemExit(f"{filename} 已存在，请在编辑器中修改已有配置")

    password = getpass("PostgreSQL 的 after_sales 用户密码（不会显示）：")
    if not password:
        raise SystemExit("数据库密码不能为空")
    database = "after_sales_test" if args.test else "after_sales"
    url = f"postgresql+psycopg://after_sales:{quote(password, safe='')}@127.0.0.1:5432/{database}"
    with target.open("x", encoding="utf-8") as file:
        if args.test:
            file.write(f"TEST_DATABASE_URL={url}\n")
        else:
            file.write(f"DATABASE_URL={url}\nJWT_SECRET={token_urlsafe(48)}\nACCESS_TOKEN_MINUTES=480\n")
    target.chmod(0o600)
    print(f"已生成 backend/{filename}，配置值不会输出到终端")


if __name__ == "__main__":
    main()
```

> **正式工程接线：** 本节完整参考使用教学工程的全局对象；当前正式工程使用 `create_app` / `app.state`。跟写本文件前先按[异步数据库与跟写约定](../../02-项目说明/异步数据库与跟写约定.md)选择该文件的替换代码，保留正式配置、密码服务和中间件，不能导入不存在的全局工厂。


对应源码：`backend/app/core/security.py`（源码见本教程对应代码块）

**作用：** 生成令牌、核对令牌、确定当前用户和管理员权限。

**固定 API / 约定：** HTTPBearer、Depends、Annotated、jwt.encode/decode、PasswordHash 按库接口使用。

**可改内容：** CurrentUser、AdminUser、DbSession 是类型别名；角色值属于前后端约定。

**阅读顺序与原因：** get_current_user 先检查令牌再查账号是否仍启用；require_admin 在这之后检查角色。不要让客户端提交的角色替代数据库里的角色。


```python
from datetime import datetime, timedelta, timezone
from typing import Annotated

import jwt
from fastapi import Depends, HTTPException
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from pwdlib import PasswordHash
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.database import get_db
from app.core.settings import settings
from app.models import User

password_hash = PasswordHash.recommended()
bearer = HTTPBearer(auto_error=False)
DbSession = Annotated[AsyncSession, Depends(get_db)]


def create_access_token(user_id: int) -> str:
    now = datetime.now(timezone.utc)
    return jwt.encode(
        {
            "sub": str(user_id),
            "iat": now,
            "exp": now + timedelta(minutes=settings.access_token_minutes),
        },
        settings.jwt_secret.get_secret_value(),
        algorithm="HS256",
    )


async def get_current_user(
    db: DbSession,
    credentials: Annotated[HTTPAuthorizationCredentials | None, Depends(bearer)],
) -> User:
    unauthorized = HTTPException(
        status_code=401,
        detail="请登录或重新登录",
        headers={"WWW-Authenticate": "Bearer"},
    )
    if credentials is None:
        raise unauthorized
    try:
        payload = jwt.decode(
            credentials.credentials,
            settings.jwt_secret.get_secret_value(),
            algorithms=["HS256"],
            options={"require": ["sub", "iat", "exp"]},
        )
        user_id = int(payload["sub"])
    except (jwt.InvalidTokenError, ValueError) as error:
        raise unauthorized from error
    user = (await db.get(User, user_id))
    if user is None or not user.is_active:
        raise unauthorized
    return user


CurrentUser = Annotated[User, Depends(get_current_user)]


def require_admin(user: CurrentUser) -> User:
    if user.role != "admin":
        raise HTTPException(status_code=403, detail="此操作需要管理员权限")
    return user
```

## frontend/src/api/http.ts

对应源码：`frontend/src/api/http.ts`（源码见本教程对应代码块）

**作用：** 复用多个接口共有的 JSON、鉴权请求头、错误和超时处理。

**固定 API / 约定：** Headers、fetch、response、AbortSignal 是浏览器 API。

**可改内容：** /api 前缀和超时参数可调整；ApiError 是项目自己的错误类型。

**阅读顺序与原因：** 先准备请求，再区分 HTTP 错误与成功响应，最后按传入 schema 校验。明确报告 HTTP 状态或后端 detail，不自动重试写请求。


```typescript
import { z } from 'zod'

const errorSchema = z.object({
  detail: z.union([
    z.string(),
    z.array(z.object({
      loc: z.array(z.union([z.string(), z.number()])),
      msg: z.string(),
    })),
  ]),
})

export class ApiError extends Error {
  constructor(public readonly status: number, message: string) {
    super(message)
    this.name = 'ApiError'
  }
}

interface RequestOptions {
  token?: string
  method?: 'GET' | 'POST' | 'PUT' | 'PATCH'
  body?: unknown
}

// 登录、配置、工单都需要 JSON 请求、错误展示和超时，因此在此复用。
export async function request<T>(
  path: string, schema: z.ZodType<T>, options: RequestOptions = {},
): Promise<T> {
  const headers = new Headers()
  if (options.token) headers.set('Authorization', `Bearer ${options.token}`)
  if (options.body !== undefined) headers.set('Content-Type', 'application/json')

  const response = await fetch('/api' + path, {
    method: options.method ?? 'GET',
    headers,
    body: options.body === undefined ? undefined : JSON.stringify(options.body),
    signal: AbortSignal.timeout(10000),
  })

  if (!response.ok) {
    let message = `请求失败：HTTP ${response.status}`
    // FastAPI 的业务/校验错误是 JSON；未处理的服务端异常可能只有文本。
    if (response.headers.get('content-type')?.includes('application/json')) {
      const { detail } = errorSchema.parse(await response.json())
      message = typeof detail === 'string'
        ? detail
        : detail.map(issue => `${issue.loc.join('.')}: ${issue.msg}`).join('；')
    }
    throw new ApiError(response.status, message)
  }

  return schema.parse(await response.json())
}
```

**作用：** 列出页面实际使用的登录、用户列表、创建客服、启停客服请求。

**固定 API / 约定：** request 的签名由本项目 http.ts 定义，z.object 等是库工具。

**可改内容：** 函数名可改；URL、HTTP 方法和字段要与后端 router/schemas 一起改。

**阅读顺序与原因：** token 作为明确参数传入，不在请求模块里偷偷读取别处的登录状态。


```typescript
import { z } from 'zod'
import { request } from './http'
import { userSchema } from './models'

const loginSchema = z.object({
  access_token: z.string().min(1), token_type: z.literal('bearer'), user: userSchema,
})

export const login = (username: string, password: string) =>
  request('/auth/login', loginSchema, { method: 'POST', body: { username, password } })

export const getCurrentUser = (token: string) =>
  request('/auth/me', userSchema, { token })

export const listUsers = (token: string) =>
  request('/users', z.array(userSchema), { token })

export const createStaff = (token: string, body: { username: string; display_name: string; password: string }) =>
  request('/users', userSchema, { token, method: 'POST', body })

export const setStaffActive = (token: string, id: number, is_active: boolean) =>
  request(`/users/${id}`, userSchema, { token, method: 'PATCH', body: { is_active } })
```

## frontend/src/router/index.ts

对应源码：`frontend/src/router/index.ts`（源码见本教程对应代码块）

**作用：** 登记页面路径，并设置前端导航限制。

**固定 API / 约定：** createRouter/createWebHistory/beforeEach 是 Vue Router API。

**可改内容：** path、meta.public、meta.admin 是本项目的页面设计约定。

**阅读顺序与原因：** 未登录访问业务页面跳登录；客服访问管理页跳正常页面。真正权限仍由后端认证依赖执行。


```typescript
import { createRouter, createWebHistory } from 'vue-router'
import { useAuthStore } from '../stores/auth'
import LoginView from '../views/LoginView.vue'
import AdminView from '../views/AdminView.vue'
import HealthView from '../views/HealthView.vue'

export const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', redirect: '/health' },
    { path: '/health', component: HealthView, meta: { public: true } },
    { path: '/login', component: LoginView, meta: { public: true } },
    { path: '/admin', component: AdminView, meta: { admin: true } },
  ],
})

router.beforeEach(async to => {
  const auth = useAuthStore()
  if (auth.token && !auth.user && to.path !== '/login') {
    try {
      await auth.restoreSession()
    } catch (error) {
      if (!(error instanceof Error)) throw error
      // 公开演示和连接检查不依赖登录，后端故障时仍允许访问。
      if (to.meta.public) return true
      return { path: '/login', query: { redirect: to.fullPath, session_error: `恢复登录失败：${error.message}` } }
    }
  }
  if (!to.meta.public && !auth.token) return '/login'
  if (to.meta.admin && auth.user?.role !== 'admin') return '/health'
})
```


## frontend/src/stores/auth.ts

对应源码：`frontend/src/stores/auth.ts`（源码见本教程对应代码块）

**作用：** 保存当前页面会话的令牌与用户，提供登录和退出。

**固定 API / 约定：** defineStore、ref 是 Pinia/Vue API。

**可改内容：** store 标识和函数名可改，但调用同步。

**阅读顺序与原因：** 登录成功后才保存服务端返回的信息。刷新后只读取令牌，向后端核验后恢复用户和角色；401 清除会话，其他失败准确报错。


```typescript
import { defineStore } from 'pinia'
import { ref } from 'vue'
import { getCurrentUser, login } from '../api/users'
import { ApiError } from '../api/http'
import type { User } from '../api/models'

const SESSION_TOKEN_KEY = 'oshino.access_token'

export const useAuthStore = defineStore('auth', () => {
  // 当前标签页刷新后保留令牌；用户身份和角色仍由后端确认。
  const token = ref(sessionStorage.getItem(SESSION_TOKEN_KEY) ?? '')
  const user = ref<User | null>(null)

  async function signIn(username: string, password: string) {
    const result = await login(username, password)
    sessionStorage.setItem(SESSION_TOKEN_KEY, result.access_token)
    token.value = result.access_token
    user.value = result.user
  }

  async function restoreSession() {
    if (!token.value) return
    try {
      user.value = await getCurrentUser(token.value)
    } catch (error) {
      if (error instanceof ApiError && error.status === 401) {
        signOut()
        return
      }
      throw error
    }
  }

  function signOut() {
    token.value = ''
    user.value = null
    sessionStorage.removeItem(SESSION_TOKEN_KEY)
  }

  return { token, user, signIn, signOut, restoreSession }
})
```

**固定 API / 约定：** Element Plus 的 el-input/el-select/el-table 按组件 API。

**可改内容：** 产品、模块、分类与客服名称由页面输入；代码中的字段名要与接口一致。

**阅读顺序与原因：** 同一配置编辑区对应三个当前存在的类别。新增模块需要选产品，编辑通过名称与 is_active 保留历史引用。

```vue
<script setup lang="ts">
import { computed, onMounted, reactive, ref } from 'vue'
import { createConfig, getCatalog, updateConfig } from '../api/config'
import type { ConfigKind } from '../api/config'
import { createStaff, listUsers, setStaffActive } from '../api/users'
import type { NamedItem, User } from '../api/models'
import { useAuthStore } from '../stores/auth'

const auth = useAuthStore()
const users = ref<User[]>([])

const staffForm = reactive({ username: '', display_name: '', password: '' })
const configKind = ref<ConfigKind>('products')
const configName = ref('')
const configActive = ref(true)
const productId = ref<number>()
const editingId = ref<number | null>(null)
const rows = computed(() => catalog.value[configKind.value])
const productNames = computed(() => Object.fromEntries(catalog.value.products.map(item => [item.id, item.name])))
const busy = ref(false)
const errorMessage = ref('')

async function load() {
  const [members, config] = await Promise.all([listUsers(auth.token), getCatalog(auth.token)])
  users.value = members
  catalog.value = config
}

onMounted(async () => {
  busy.value = true
  try {
    await load()
  } catch (error) {
    if (!(error instanceof Error)) throw error
    errorMessage.value = error.message
  } finally {
    busy.value = false
  }
})

function resetConfigForm() {
  editingId.value = null
  configName.value = ''
  configActive.value = true
  productId.value = undefined
}

function editConfig(item: NamedItem) {
  editingId.value = item.id
  configName.value = item.name
  configActive.value = item.is_active
}

async function saveConfig() {
  errorMessage.value = ''
  if (configKind.value === 'modules' && editingId.value === null && productId.value === undefined) {
    errorMessage.value = '请先选择模块所属产品'
    return
  }
  busy.value = true
  try {
    if (editingId.value === null) {
      await createConfig(auth.token, configKind.value, configName.value, productId.value)
    } else {
      await updateConfig(auth.token, configKind.value, editingId.value, configName.value, configActive.value)
    }
    resetConfigForm()
    await load()
  } catch (error) {
    if (!(error instanceof Error)) throw error
    errorMessage.value = error.message
  } finally {
    busy.value = false
  }
}

  busy.value = true
  errorMessage.value = ''
  try {
    await createStaff(auth.token, staffForm)
    staffForm.username = ''
    staffForm.display_name = ''
    staffForm.password = ''
    await load()
  } catch (error) {
    if (!(error instanceof Error)) throw error
    errorMessage.value = error.message
  } finally {
    busy.value = false
  }
}

async function toggleStaff(user: User) {
  busy.value = true
  errorMessage.value = ''
  try {
    await setStaffActive(auth.token, user.id, !user.is_active)
    await load()
  } catch (error) {
    if (!(error instanceof Error)) throw error
    errorMessage.value = error.message
  } finally {
    busy.value = false
  }
}
</script>
```

```python
import asyncio
import pytest

from app import seed


@pytest.mark.parametrize(
    ("username", "password", "invalid_field"),
    [("admin", "x9Q!", "password"), ("invalid-name", "Only-for-review-8392", "username")],
)
def test_invalid_admin_input_reports_error_without_password(
    monkeypatch, username, password, invalid_field
):
    monkeypatch.setattr(
        "sys.argv", ["seed", "--username", username, "--display-name", "测试管理员"]
    )
    monkeypatch.setattr(seed, "getpass", lambda prompt: password)

    with pytest.raises(SystemExit) as error:
        asyncio.run(seed.main())

    message = str(error.value)
    assert invalid_field in message
    assert password not in message
```

```python
from fastapi import APIRouter, HTTPException, Query
from sqlalchemy import func, or_, select

from app.core.security import CurrentUser, DbSession
from app.models import Ticket
from app.modules.tickets.schemas import (
    CloseRequest,
    NoteRequest,

    TicketStatus,
)

    add_record,

    validate_owner,

router = APIRouter(prefix="/api/tickets", tags=["工单"])


@router.post("", response_model=TicketDetail, status_code=201)
async def create_ticket(body: TicketCreate, db: DbSession, user: CurrentUser):
    await validate_catalog(db, body.product_id, body.module_id, body.category_id)
    ticket = Ticket(**body.model_dump(), owner_id=user.id)
    add_record(ticket, user.id, "created", "创建工单，状态为待处理")
    db.add(ticket)
    await db.commit()
    return ticket


@router.get("", response_model=TicketPage)
async def list_tickets(
    db: DbSession,
    user: CurrentUser,
    page: Annotated[int, Query(ge=1)] = 1,
    page_size: Annotated[int, Query(ge=1, le=100)] = 20,
    keyword: Annotated[str | None, Query(max_length=200)] = None,
    status: TicketStatus | None = None,
    priority: Priority | None = None,
    product_id: Annotated[int | None, Query(gt=0)] = None,
    module_id: Annotated[int | None, Query(gt=0)] = None,
    category_id: Annotated[int | None, Query(gt=0)] = None,
    owner_id: Annotated[int | None, Query(gt=0)] = None,
):
    filters = []
    if keyword:
        filters.append(
            or_(Ticket.title.ilike(f"%{keyword}%"), Ticket.description.ilike(f"%{keyword}%"))
        )
    for column, value in [
        (Ticket.status, status),
        (Ticket.priority, priority),
        (Ticket.product_id, product_id),
        (Ticket.module_id, module_id),
        (Ticket.category_id, category_id),
        (Ticket.owner_id, owner_id),
    ]:
        if value is not None:
            filters.append(column == value)
    total = (await db.scalar(select(func.count()).select_from(Ticket).where(*filters)))
    items = (await db.scalars(
        select(Ticket)
        .where(*filters)
        .order_by(Ticket.id.desc())
        .offset((page - 1) * page_size)
        .limit(page_size)
    )).all()
    return {"items": items, "total": total, "page": page, "page_size": page_size}

@router.patch("/{ticket_id}", response_model=TicketDetail)
async def update_ticket(ticket_id: int, body: TicketPatch, db: DbSession, user: CurrentUser):
    ticket = (await lock_ticket(db, ticket_id))
    changes = body.model_dump(exclude_unset=True)
    (await validate_catalog(
        db,
        changes.get("product_id", ticket.product_id),
        changes.get("module_id", ticket.module_id),
        changes.get("category_id", ticket.category_id),
        current=ticket,
    ))
    if "owner_id" in changes and changes["owner_id"] != ticket.owner_id:
        await validate_owner(db, changes["owner_id"])
    for field, value in changes.items():
        setattr(ticket, field, value)
    add_record(ticket, user.id, "updated", "更新了工单信息")
    await db.commit()
    return ticket

    ticket.solution = body.solution
    ticket.status = "resolved"
    add_record(ticket, user.id, "status", "保存解决方案：处理中 → 已解决")
```

```python
from typing import Annotated, Literal, Self

from pydantic import BaseModel, ConfigDict, EmailStr, Field, StringConstraints, model_validator

Title = Annotated[str, StringConstraints(strip_whitespace=True, min_length=1, max_length=200)]
Description = Annotated[
    str, StringConstraints(strip_whitespace=True, min_length=1, max_length=10000)
]

    str, StringConstraints(strip_whitespace=True, min_length=1, max_length=100)
]
Priority = Literal["P1", "P2", "P3", "P4"]
TicketStatus = Literal["pending", "processing", "resolved", "closed"]
PositiveId = Annotated[int, Field(gt=0)]


class TicketCreate(BaseModel):
    model_config = ConfigDict(extra="forbid")
    title: Title
    description: Description
    customer_name: CustomerName
    customer_email: EmailStr
    product_id: PositiveId
    module_id: PositiveId
    category_id: PositiveId

class TicketPatch(BaseModel):
    model_config = ConfigDict(extra="forbid")
    title: Title | None = None
    description: Description | None = None
    customer_name: CustomerName | None = None
    customer_email: EmailStr | None = None
    product_id: PositiveId | None = None
    module_id: PositiveId | None = None
    category_id: PositiveId | None = None
    owner_id: PositiveId | None = None
    priority: Priority | None = None

    @model_validator(mode="after")
    def reject_empty_changes(self) -> Self:
        # PATCH 中省略字段表示不修改；显式 null 不能清空这些必填字段。
        if not self.model_fields_set:
            raise ValueError("至少提交一个需要修改的字段")
        for field in self.model_fields_set:
            if getattr(self, field) is None:
                raise ValueError(f"{field} 不能设为 null")
        return self
```

**作用：** 放多个工单接口会实际使用的读取、锁定、配置/负责人检查和记录操作。

**固定 API / 约定：** select、with_for_update、Session 是数据库 API。

**阅读顺序与原因：** 这层函数都有当前调用方。lock_ticket 在写入前锁行；add_record 只准备修改，由调用接口统一提交。


```python
from datetime import datetime, timezone

from fastapi import HTTPException
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models import Product, ProductModule, Ticket, TicketCategory, TicketRecord, User


async def get_ticket(db: AsyncSession, ticket_id: int) -> Ticket:
    ticket = (await db.get(Ticket, ticket_id))
    if ticket is None:
        raise HTTPException(status_code=404, detail="工单不存在")
    return ticket


async def lock_ticket(db: AsyncSession, ticket_id: int) -> Ticket:
    # 同一工单的写操作排队执行，避免两名客服同时推进状态。
    ticket = (await db.scalar(select(Ticket).where(Ticket.id == ticket_id).with_for_update()))
    if ticket is None:
        raise HTTPException(status_code=404, detail="工单不存在")
    if ticket.status == "closed":
        raise HTTPException(status_code=409, detail="已关闭工单只允许查看")
    return ticket


async def validate_catalog(
    db: AsyncSession,
    product_id: int,
    module_id: int,
    category_id: int,
    current: Ticket | None = None,
) -> None:
    product = (await db.get(Product, product_id))
    module = (await db.get(ProductModule, module_id))
    category = (await db.get(TicketCategory, category_id))
    if product is None or module is None or category is None:
        raise HTTPException(status_code=422, detail="产品、模块或分类不存在")
    if module.product_id != product.id:
        raise HTTPException(status_code=422, detail="模块不属于所选产品")
    for field, item in [("product_id", product), ("module_id", module), ("category_id", category)]:
        unchanged = current is not None and getattr(current, field) == item.id
        if not unchanged and not item.is_active:
            raise HTTPException(status_code=422, detail="新工单或新选择必须使用启用的配置")


async def validate_owner(db: AsyncSession, owner_id: int) -> None:
    owner = (await db.get(User, owner_id))
    if owner is None or not owner.is_active:
        raise HTTPException(status_code=422, detail="负责人必须是启用的用户")


def add_record(ticket: Ticket, author_id: int, kind: str, content: str) -> None:
    ticket.updated_at = datetime.now(timezone.utc)
    ticket.records.append(TicketRecord(author_id=author_id, kind=kind, content=content))
```

## frontend/src/router/index.ts

**作用：** 登记页面路径，并设置前端导航限制。

**固定 API / 约定：** createRouter/createWebHistory/beforeEach 是 Vue Router API。

**可改内容：** path、meta.public、meta.admin 是本项目的页面设计约定。

**阅读顺序与原因：** 未登录访问业务页面跳登录；客服访问管理页跳正常页面。真正权限仍由后端认证依赖执行。


```typescript
import { createRouter, createWebHistory } from 'vue-router'
import { useAuthStore } from '../stores/auth'
import LoginView from '../views/LoginView.vue'
import TicketsView from '../views/TicketsView.vue'
import TicketEditor from '../views/TicketEditor.vue'
import TicketDetailView from '../views/TicketDetailView.vue'
import AdminView from '../views/AdminView.vue'
import HealthView from '../views/HealthView.vue'

export const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', redirect: '/tickets' },
    { path: '/health', component: HealthView, meta: { public: true } },
    { path: '/login', component: LoginView, meta: { public: true } },
    { path: '/tickets', component: TicketsView },
    { path: '/tickets/new', component: TicketEditor },
    { path: '/tickets/:id', component: TicketDetailView },
    { path: '/tickets/:id/edit', component: TicketEditor },
    { path: '/admin', component: AdminView, meta: { admin: true } },
  ],
})

router.beforeEach(async to => {
  const auth = useAuthStore()
  if (auth.token && !auth.user && to.path !== '/login') {
    try {
      await auth.restoreSession()
    } catch (error) {
      if (!(error instanceof Error)) throw error
      // 公开演示和连接检查不依赖登录，后端故障时仍允许访问。
      if (to.meta.public) return true
```

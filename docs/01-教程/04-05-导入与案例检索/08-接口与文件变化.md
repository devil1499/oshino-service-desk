# 接口与文件变化

| 阶段 | 方法与地址 | 权限与效果 |
|---|---|---|
| 第四部分 | POST /api/tickets/import | 管理员；multipart 的 file 字段；成功 201，返回 imported 和 ticket_ids |
| 第五部分 | POST /api/tickets/{ticket_id}/similar | 登录用户；无需请求体；返回 items、expanded、stale_count、indexed_at |

导入失败：文件过大 413、字段或配置不合法 422、编号重复 409；无权限沿用现有鉴权。相似案例失败：工单不存在 404、配置/索引未就绪 503、模型调用或响应不合法 502。其他未处理故障按服务器错误暴露，不返回伪造成功。

数据库唯一变化：tickets.import_key（可空、唯一）。执行 alembic upgrade head 后旧记录保留；第五部分只增加派生索引文件和独立配置，不新增业务表。

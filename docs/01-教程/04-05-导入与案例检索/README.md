## 跟写时的依赖安装

在 WSL 的 `/mnt/e/oshino/frontend` 目录操作：如果自己填写了 `package.json`、还没有 `package-lock.json`，先运行 `npm install` 生成锁文件。若已有配套的依赖清单和锁文件，运行 `npm ci`。锁文件不需要手抄，也不要把旧阶段的锁文件与新依赖清单混用。之后运行 `npm run typecheck`、`npm run build`，通过后再 `npm run dev`。

按阶段对照新增和修改的代码，不把不同阶段的同名文件随意覆盖。深色三栏工作台在第八部分后的“工作台界面改版”中；前面的简洁页面用于逐步学习。

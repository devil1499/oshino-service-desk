# 接口和文件变化

> 2026-10-18 流畅度更新：最终第八部分现已采用出处抽屉、列表状态保留、按需加载及等待反馈。最新行为、跟写顺序和验证范围见 [流畅度优化说明](18-工作台流畅度优化.md)。本页早先的新标签行为和单包体积记录为历史版本。

| 部分 | 接口 | 用途 |
|---|---|---|
| 六 | GET/POST /api/knowledge | 分页读文档/管理员录入 |
| 六 | POST /api/knowledge/upload | 管理员上传MD/TXT，multipart字段file/title/product_id/module_id/category_id |
| 六 | GET /api/knowledge/{id} | 读文档，客服限已发布 |
| 六 | PUT /api/knowledge/{id}/content | 管理员保存草稿 |
| 六 | POST /api/knowledge/{id}/publish 或 disable | 管理员发布/停用 |
| 六 | POST /api/tickets/{id}/knowledge | 登录后检索知识 |
| 七 | POST /api/tickets/{id}/assist | 登录后生成建议，成功201 |
| 七 | GET /api/tickets/{id}/assistance?page=1 | 每页10条历史 |
| 七 | POST /api/tickets/{id}/assistance/{run_id}/adopt | confirmed/solution/reply，人工确认采用 |
| 八 | POST /api/tickets/{id}/similar?mode=hybrid | 案例检索，mode也可bm25/dense |
| 八 | GET /api/evaluation/config | 登录后读实验配置，不含密钥 |

数据库升级顺序：04_import_key → 06_knowledge → 07_assistance。第六部分新增两表，第七部分新增建议表，第八部分不加表。配置沿用.env和.env.retrieval，第七部分新增.env.chat。错误401/403为登录/权限，404不存在，409状态或版本冲突，413文件过大，422输入不合约，503检索/配置未就绪，502远程模型失败。

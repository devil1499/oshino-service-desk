# 知识库切分、清洗与向量化速查

这份补充讲通用方法，不仅适用于工单系统。第六部分的 500 字符、80 字符重叠是教学基线，不代表所有知识库的最佳参数。

## 1. 通用来说怎么做效果更好

没有固定“最强组合”。优先建立这条可评测的基线：

**结构化解析 → 清洗 → 按内容边界切分 → 加标题/章节上下文 → Embedding → 向量与 BM25 混合检索 → 重排序 → 按需补齐上下文。**

| 环节 | 推荐起点 |
|---|---|
| 解析 | 保留标题、段落、列表、表格表头/单位、出处位置；可评估 Docling |
| 切分 | FAQ 一问一答；手册按小节/步骤；合同按条款；代码按函数/类 |
| 长度 | 试验 256、512、768 tokens，重叠 0 或约 10%；用实际模型 tokenizer 计数 |
| 上下文 | 每块附文档标题和章节路径；必要说明与原文分开保存 |
| 父子块 | 小块参与检索，命中后补父章节或相邻片段；控制总 token 预算 |
| 模型 | 比较适合语言与领域的候选，如 Qwen3 Embedding、BGE-M3；不是参数越大越好 |
| 检索 | 语义向量找近义表达，BM25 找错误码/型号；融合排名后重排，不直接相加原始分数 |

模型、维度、归一化、query/document 指令必须按模型说明一致配置。修改模型或编码规则后重建索引；长上下文模型不代表每个片段都应塞满。

语义切分、Late Chunking、多向量和视觉检索是针对性方案，不是必须一起上。Late Chunking 是先编码长文本得到 token 表示，再按块聚合；不是把全文的一个向量切成几段。图表承载主要知识时，单靠 OCR 文本可能不够。

## 2. PDF 是不是只能 OCR

不是。文字 PDF 优先直接提取；扫描页需要 OCR；混合 PDF 逐页判断；已有可靠文字层时不重复识别。能复制正确正文是一个简单线索，不是最终质量保证。表格、多栏、图片说明仍需检查阅读顺序。

## 3. 怎么判断切分做对了

- **内容完整**：没有丢正文、单位、否定词、适用条件、警告和表格关系。
- **意思清楚**：一块围绕一个主题；“它”“上述方法”等能通过标题或父块补足背景。
- **能够追溯**：知道文档 ID、版本、章节、页码或原文块位置。
- **长度有效**：不超过模型限制，不发生静默截断。
- **检索有效**：真实问题能取回足够证据，而不仅是主题相似的段落。

例：“仅设备离线时可复位。长按 5 秒。会清除网络配置。”应作为完整操作单元；不能只召回“长按 5 秒”而遗漏条件与后果。

先分类型抽查 30—50 块，再用独立问题集测 Recall@K、排序和回答引用。标准答案标注原文证据位置，不只标 chunk ID；比较方案时固定模型、检索配置和总上下文预算。检索失败先确认正确证据是否完整存在，别把所有问题归咎于切分。

## 4. 数据清洗怎么做

| 噪声或问题 | 怎么处理 |
|---|---|
| 重复页眉页脚 | 按页面位置和重复模式识别，从检索正文移除；保留原文件 |
| 排版断行、空白 | 确认不是段落/代码/表格边界后合并，不全局删除换行 |
| OCR 错字 | 对照原图修正；不确定的标记复核，不凭常识补数字 |
| 表格被打散 | 重建表头—行列—单位关系，保留脚注 |
| 重复资料 | 哈希识别完全重复；近似重复核对版本及来源，不仅凭标题删除 |
| 旧版资料 | 记录版本、有效状态和适用范围，避免新旧内容混答 |
| 私有内容 | 按业务权限过滤或脱敏，权限由后端执行 |

保留原始文件、解析结果、清洗结果和处理规则版本。对比关键数字、型号、单位、否定词和段落覆盖；异常大量删减进入复核。“≤”与“≥”、“0.5”与“5”、“允许”与“不允许”不能随意归一化。

## 5. 格式怎么定

机器处理用结构化 JSON，人工预览用 Markdown。下面是建议的数据契约，不是必须照搬到现有数据库的迁移：

```json
{
  "schema_version": "1",
  "document_id": "device-a-manual",
  "revision_id": "rev-003",
  "chunk_id": "device-a-manual:rev-003:012",
  "title": "设备 A 使用手册",
  "section_path": ["故障处理", "恢复连接"],
  "content_type": "procedure",
  "content": "仅设备离线时可复位。长按复位键 5 秒，会清除网络配置。",
  "context_text": "设备 A 使用手册 > 故障处理 > 恢复连接",
  "source_blocks": [{"block_id": "block-037", "page_number": 3}],
  "status": "published"
}
```

`content` 是忠于原文的清洗正文；`context_text` 是检索背景，若由模型生成，另记生成来源和版本。Embedding 输入可由标题、章节、正文拼接；内部 ID、权限、导入时间通常只作元数据。没有真实页码不编造，用锚点或解析块定位。索引配置另记模型版本、维度、切分和拼接规则版本。

## 6. 三个验收问题

1. 清洗后，原文的重要事实还在吗？
2. 切分后，回答问题所需证据能完整取回吗？
3. 返回后，能定位到正确原文及版本吗？

通过后再评测耗时、存储和调用成本，选择满足预算的方案；不要引用别人的提升百分比作为自己的实验成绩。

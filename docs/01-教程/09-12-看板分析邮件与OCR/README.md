代码块路径中的 `backend`、`frontend`、`data`、`scripts` 分别对应你正式工程中的同名目录。跟写代码时保留本机配置、数据库和用户改动。新增表通过 Alembic 升级，沿用已有迁移历史。

统计数据从 PostgreSQL 查询。基础分析调用你配置的聊天模型，人工采用后才改工单。邮件只发到你配置的测试收件人，并保存 SMTP 结果。OCR 仅把资料转为草稿，管理员校对、保存、发布并重建知识索引后才能用于检索。

真实模型效果、真实 SMTP 收件和本机 OCR 权重推理需要你按验收清单实测。测试中的模拟响应不是论文实验结果。

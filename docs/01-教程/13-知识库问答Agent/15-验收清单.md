## 页面和真实模型人工验收

- [ ] 用户 A 创建的会话，用户 B 读取和发送消息均被拒绝。
- [ ] 同一 request_id 重复发送不重复调用模型；正文不同返回 409。
- [ ] 同一会话并发两次发送，最多一轮进入 running。
- [ ] 问“下一步呢”，能结合上文形成完整问题；没有上文时明确追问。
- [ ] 选产品 A 不返回产品 B 的资料；历史问答不能自行扩大范围。
- [ ] 草稿、停用和索引过期的文档不作为本轮依据。
- [ ] 生成期间停用资料，返回 409，本轮记录变为 failed，同会话可以重新提问。
- [ ] 模型未知异常或请求取消后，不残留 running；记录失败后同会话可以继续提问。
- [ ] 刷新时发现 running，读取历史直至终态；不会重复发送，切换会话后停止轮询。
- [ ] 每个来源点击后能定位到正确文档；查看仍检查权限。
- [ ] 刷新后会话、回答、失败记录仍存在；重启中断的请求显示失败。
- [ ] 模型超时、非法 JSON、索引缺失、配置缺失分别给出准确错误。
- [ ] 资料中包含“忽略规则”时，系统仍只执行限定检索流程。
- [ ] 浏览器刷新、切换会话、读取较早消息和展开来源均正常。

# 管理中心表单改版

用户已确认蓝白效果图：左侧资料列表，右侧新增或编辑表单。

## 设计与范围

- 管理中心只有一层导航：数据统计、人员管理、基础资料、历史导入。后两项仅管理员可见。
- 人员管理合并客户名单和客服账号管理；复用现有人员查询、客服创建和启停接口。
- 基础资料默认显示产品，可选择模块、问题分类并按名称搜索。编辑时带入现有值；模块所属产品只读，沿用现有接口契约。
- 新建资料默认启用，编辑可启停；保存失败保留表单输入，保存成功刷新失败单独提示。
- 移除连接检查导航入口，保留健康接口和直接访问地址；不删除业务数据。
- 本次不增加 Agent 评测或反馈，也不改变客户端业务。

## 执行步骤

1. 更新导航行为测试，确认旧实现不能通过；修改导航与路由，兼容旧导入地址。
2. 将 AdminView 缩为基础资料页面；使用真实接口，在页面右侧填写表单，模块关联只读。
3. 人员管理集中显示客户与客服，管理员可新增、启停客服；历史导入独立页面复用 ImportView。
4. 运行前端测试和构建，并用浏览器验证新增、编辑、错误保留输入、类型切换、权限和导入入口。

## 验证边界

导航以 Node 测试验证；页面以浏览器验证。使用模拟响应时明确标注，不作为真实数据库写入证明。无需改后端数据库或安装项目依赖。不提交、不推送、不部署。

## 实施结果

- 基础资料默认显示产品，列表每页 10 条；新增与编辑使用右侧表单。新建沿用后端默认启用，编辑可停用。
- 人员管理复用现有两个查询接口，合并启用客户与全部客服（包含停用账号），不重复显示客服；客户用户名未由接口提供，显示“—”。
- 旧人员页面的重复展示代码已移除；客户产品与服务守则保留。原导入地址重定向至独立页面。
- 浏览器模拟接口检查通过：模块关联回填、错误保留输入、修改启停、新增、搜索、人员合并、客服创建和启停。
- 真实后端浏览器检查通过：管理员登录、读取资料、原值保存、人员列表、CSV 上传弹窗；普通客服只有读取入口，不能进入管理导入页。
- 前端测试与构建通过；构建保留已有的大包体积提示。本次未重新进行 CSV 文件导入或创建真实客服账号。

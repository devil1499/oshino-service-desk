# 登录保持与八小时有效期

## 改动

- 后端默认有效期、Docker 环境变量、WSL 本地配置、配置示例和初始化脚本统一为 480 分钟（8 小时）。
- 前端仅把令牌保存在当前标签页的 sessionStorage，不保存密码或缓存角色。刷新后调用 /api/auth/me 核验用户，再执行页面权限判断。
- 退出登录清除内存和 sessionStorage；凭证失效或账号停用时，恢复接口返回 401 并清除会话。
- 恢复时的服务故障保留令牌并显示准确错误，服务恢复后可重试；公开演示与连接检查仍允许访问。
- 登录页提示、基础教程、后续教程中重复的认证代码及相关说明同步更新。

8 小时从登录成功时计算，刷新不续期。旧凭证不会被延长，需要重新登录获取新凭证。本次浏览器验收已重新登录。

## 验证

- 先运行回归测试，确认原代码没有保存会话、令牌仅 1 小时，测试失败；实施后相关测试通过。
- 前端 9 项测试通过，包括刷新恢复、退出、失效凭证、上游故障、无凭证场景。
- 后端基础 7 项测试通过，包含 JWT 到期时间与签发时间相差 28800 秒的校验；Ruff 检查通过。
- 前端类型检查和构建通过，保留原有主包超过 500 kB 的警告。
- 真实 Docker 登录接口新签发凭证已核验为 28800 秒，没有输出或记录令牌正文。
- 浏览器已验证工单详情和基础管理页刷新后仍保持正确用户身份，退出后访问基础管理会跳回登录。
- 另外短暂停止后端验证恢复失败：受保护页显示 HTTP 502 的准确错误；启动后端后直接访问基础管理，使用原会话恢复成功，没有重新输入密码。
- Docker 后端已恢复 healthy，当前页面保持登录。截图保存于 `.local/auth-session/after-refresh.png`。

这些检查没有等待真实 8 小时，而是核验签发声明及已有的过期校验逻辑。

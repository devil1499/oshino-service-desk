# 前三部分代码与讲解计划

按用户已确认的八部分划分，交付前三部分，用户自行填写正式工程。
本包独立于原有 backend、frontend；不读取原项目密钥，不提交 Git。

## 已确定的范围

1. 连通性：FastAPI /api/health、Vue 页面、Vite 代理。
2. 用户基础：PostgreSQL 迁移、命令行创建管理员、账号密码登录、管理员创建/停用客服、产品/模块/分类的新增、改名与停用。
3. 工单闭环：创建、分页筛选、详情、修改、处理记录、开始处理、填写解决方案、人工确认回复后关闭。

业务约定：登录用户均可查看/处理内部工单；负责人用于分工，不是数据隔离权限。
管理员维护基础配置与客服账号；管理员由命令行初始化。
第一阶段不连接数据库；第二、三阶段共用 03-tickets 工程。
第三阶段客户回复由人工在系统外完成；关闭时记录人工确认，SMTP 集成属于第七部分。
关闭后工单只读；历史分类与产品关联通过停用保留。
工单状态不能跳步；记录修改人和每次状态变化；每个写操作使用数据库事务。

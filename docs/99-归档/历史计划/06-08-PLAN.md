# 第六至第八部分计划

用户已按图确认范围并要求直接完成、自己验收。沿用第五部分，独立参考工程；不改正式工程，不调用子代理，不提交发布。

## 设计与范围
- 第六部分：管理员上传 UTF-8 Markdown/TXT 或直接录入文本，预览编辑后发布；约500字符、80字符重叠分块，存 PostgreSQL；停后端后独立命令重建知识 Milvus Collection。保留案例索引，知识与案例分别就绪标记；当前版本只实现文本知识，不扩展旧总设计中的 OCR/PDF/SMTP。
- 第七部分：按钮触发双源检索（各最多5条），聊天模型重排最多10候选并选最多5条；结构化生成分析、分类/优先级建议、步骤、风险、待确认项和回复草稿；校验引用，保存生成快照；人工编辑并确认采用，写处理记录，不自动改工单状态或发送邮件。模型失败、无依据、引用造假和工单/来源变更均准确报错。
- 第八部分：用户验收清单、运行说明、独立评测输入模板、真实接口批量评测与人工评分统计脚本、论文实验/截图模板。不编造实验结果和截图，不把目标当实测。

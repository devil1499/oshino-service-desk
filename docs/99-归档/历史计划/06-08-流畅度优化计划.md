# 工作台流畅度优化

> 2026-10-18 流畅度更新：最终第八部分现已采用出处抽屉、列表状态保留、按需加载及等待反馈。最新行为、跟写顺序和验证范围见 [流畅度优化说明](../../01-教程/06-08-知识库与AI建议/18-工作台流畅度优化.md)。本页早先的新标签行为和单包体积记录为历史版本。

用户已确认实施此前提出的优化方案。仅更新第八部分参考工程，不覆盖正式工程，不提交、不部署。

1. 路由改为动态导入；Element Plus 在使用处导入组件和样式，保留全局 loading 指令。不新增运行依赖。
2. 工单详情把分类映射传入 AI 面板，去掉重复的基础配置请求。
3. 新增只读出处抽屉，通过现有详情接口获取工单或知识，保留当前工单及草稿，不跳转、不共享或持久化令牌。
4. 工作台 KeepAlive 仅保留工单列表，返回时刷新列表、配置和用户，同时恢复筛选、页码和滚动位置。退出登录销毁缓存。
5. 详情首次加载使用占位，检索和 AI 更新时保留旧内容，标明更新状态；失败保留输入，不伪造进度。长案例方案可展开。支持减少动画偏好。
6. 用真实 Vue 页面与模拟 API 做浏览器回归；比较构建入口大小、配置请求次数，检查抽屉草稿保留、列表返回、失败显示。运行类型检查、构建和登录导航回归。
7. 更新完整源码讲解、界面说明、验收清单和文件哈希，重新打包第六至八部分。

不把模拟接口测试当成真实模型、数据库验收；本次不改后端 API。

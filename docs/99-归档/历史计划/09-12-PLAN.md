- [x] 增加按需加载的深色统计页面和导航，使用 CSS 条形图，无新增图表依赖。
- [x] 先以 API 测试验证真实聚合、空集、筛选和登录约束，再实现；验证迁移、类型和构建。

## 第十部分：自动分析

- [x] 新建工单时保存独立分析任务，通过 FastAPI 后台任务生成摘要、分类、优先级及原因。CSV 历史导入不触发模型。
- [x] 分析模型复用现有 ChatClient 和配置；结果校验有效分类 ID。建议不会直接覆盖人工字段。
- [x] GET 查看任务、POST 手动重做、POST 确认采用分类和优先级；指纹过期拒绝采用。后台使用独立数据库会话。
- [x] 单进程启动时将上次未完成任务标记中断；前端仅在任务进行中轮询，离开页面清理。
- [x] 测试创建触发、失败保存、重复触发、过期结果、采用和已关闭权限；提供 mock 模型与真实模型的验收区分。

## 第十一部分：SMTP

- [x] `.env.smtp` 配置 TLS、认证、发件人和测试收件人白名单，配置错误返回明确提示。凭据不进入日志或包。
- [x] 显式确认、保存发送请求后才调用 SMTP。请求 UUID 唯一；同一请求再次提交返回原记录，不重复投递。相同 UUID 不同内容拒绝。
- [x] 结果分 sending、accepted（SMTP 已接受，不代表最终送达）、failed（明确拒绝）和 unknown（连接中断/超时，无法确认）。unknown 不自动重试。
- [x] 关联原 AI 建议并保存最终地址、主题、正文与结果。人工编辑、确认发送、刷新记录；使用测试邮箱。
- [x] 测试确认、白名单、闭单限制、重复请求、SMTP 拒绝及不确定结果，测试只使用假传输或本地服务器。

## 第十二部分：OCR 与 PDF

- [x] 在原知识上传边界增加 JPG、PNG、普通 PDF、扫描 PDF；文本 PDF 优先提取，缺少文本的页面 OCR。
- [x] 限制文件 10 MiB、图片 1600 万像素、PDF 20 页与单页尺寸；加密/损坏文件准确拒绝；原文件只在临时目录使用。
- [x] PaddleOCR 在独立进程执行，限制运行时长，进程终止回收资源。使用已有 CPU 依赖；明确模型下载准备方法。
- [x] 识别后仅创建知识草稿，沿用现有校对、发布、分块、重建索引流程。失败不生成伪造正文。
- [x] 测试解析边界、PDF 直接提取、OCR 合并、超时和草稿权限；真实模型权重与识别效果单独记录。

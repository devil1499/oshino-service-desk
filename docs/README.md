# 文档与跟写入口

平时从这一页进入。教程按阶段放在 `01-教程`，运行说明、检查记录、工具与历史资料各自归类。

## 你现在从哪里开始

第一至第十三部分已有正式代码。案例与知识检索继续使用本地 Qwen3-Embedding-0.6B；聊天 API 需自行填写配置，真实生成质量尚未验收。智能助手从[第十三部分](01-教程/13-知识库问答Agent/README.md)开始跟写；第三部分设计见[工单管理闭环](01-教程/01-03-基础与工单/03-工单管理闭环.md)。

登录、基础管理、工单、知识库和智能助手连接真实后端；统计看板读取真实数据库。已有基础代码与旧参考写法不同时，以正式工程和[接线约定](02-项目说明/异步数据库与跟写约定.md)为准。

## 目录怎么分

```text
docs/
├── README.md          从这里开始
├── 01-教程/           按 01—13 的顺序跟写
├── 02-项目说明/       启动、账号、接线与项目目录
├── 03-检查记录/       当前及历史验证结果
├── 04-工具/           文档检查脚本
└── 99-归档/           历史计划、原参考包清单与草稿
```

[归档说明](99-归档/README.md)中的旧清单只对应原参考包，不能用于验证当前目录。

前八部分中“暂不包含 OCR/邮件”等说明指当时阶段；这些扩展安排在第九至十二部分。各篇旧检查记录保留其历史日期，不代表本轮重新执行。模型效果、真实邮件送达、OCR 质量和论文实验数据要按清单实际验收。
